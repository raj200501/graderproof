# Roman numerals

Write a Python module `roman.py` with a function `to_roman(n)` that returns the Roman numeral for an integer `n` from 1 to 3999, using the standard subtractive notation (`IV`, `IX`, `XL`, `XC`, `CD`, `CM`) and uppercase letters. For example, `to_roman(1994)` returns `"MCMXCIV"`.

If `n` is outside 1 to 3999, raise `ValueError`.

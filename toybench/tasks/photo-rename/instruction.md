# Rename camera photos

The camera names photos `IMG_YYYYMMDD_HHMMSS.jpg`. Rename every file in `photos/` whose name matches that pattern exactly (uppercase `IMG_`, eight digits, `_`, six digits, `.jpg`) to `YYYY-MM-DD_HH-MM-SS.jpg`. For example, `IMG_20260712_143005.jpg` becomes `2026-07-12_14-30-05.jpg`.

Do not change any file's contents. Leave every other file in `photos/` exactly as it is.

# Transpose a TSV table

`matrix.tsv` is a tab-separated table in which every row has the same number of cells. Write `transposed.tsv` with rows and columns swapped: the cell in row i, column j of the output is the cell in row j, column i of the input.

Write the output in the same format: cells separated by a single tab character, every row (including the last) terminated by a newline, and cell text unchanged (cells may contain spaces).
